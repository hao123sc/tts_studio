# TTS Studio 配音工作站（P1 网络数字配音）

> 左边一列"配音的人"，中间贴台词（可多段），右边调参数，点一下生成，批量导出 MP3 和清单。
> Windows 桌面软件 · 全中文界面 · 免费免 Key（Edge-TTS）· 离线兜底（系统 SAPI）。

本仓库对应《配音软件-需求文档（P1网络数字配音+P2音色克隆）》，按 M0→M4 里程碑实施。
P2（音色克隆）不在本期范围，但引擎插件目录与接口已按文档 §3.1 预留。

---

## 一、安装

**要求**：Windows 10/11 x64（主），Python 3.11+（仅从源码运行时需要；exe 用户不需要）。

```bash
# 1. 安装 Python 3.11 或更高版本（勾选 "Add to PATH"）
# 2. 在本目录打开命令行，执行：
pip install -r requirements.txt
```

> Linux/macOS 也可运行（开发调试用）；离线兜底需要系统有 espeak 等语音后端。

## 二、运行

```bash
python app/main.py
# 或
python -m app.main
```

**最小使用流程**：

1. 左侧选音色（如"云希"），点「▶ 试听」确认声音；
2. 中间「📥 导入CSV」导入 `示例数据/蚕茧课程41段.csv`（或直接粘贴台词，一段一行）；
3. 右侧调参数（默认即可：44.1kHz、单声道、峰值 −3dBFS、`{i:02d}.mp3`）；
4. 点「🎙 生成全部」→ 逐条出 `01.mp3 … 41.mp3`，同时写 `清单.csv`；
5. 改了某段再点「🔁 只重做这一段」，其余不动；
6. 点「📦 导出交付包」得到 zip（音频 + 清单.csv + 参数.json + README.txt）。

## 五、功能速查

- **音色**：Edge-TTS 动态拉取（失败自动用内置清单）＋ Windows SAPI 离线兜底；分组/搜索/收藏/试听缓存；每段可指定不同音色（教师/学生甲/学生乙）。
- **文本**：多段编辑、TXT/CSV/Markdown 导入（CSV 列：`序号,文件名,文本,音色,语速,音调,音量,备注`）、`[pause=1.5]`/`[[停顿1.5s]]` 停顿标记（界面高亮）、发音词典、数字/单位/缩写读法规则、文本校验、一键拆句。
- **参数**：语速 −50%~+100%、音调 ±12 半音、音量 ±12 dB、风格（不支持的引擎置灰并说明）、采样率/码率/声道/响度归一/输出格式/命名模板；参数随音色记忆；内置 3 套预设（旁白/学生/新闻），可另存、导入导出。
- **生成**：全部/仅勾选/仅这一段/仅失败；串行队列、进度与剩余时间；断点续传（文本+参数哈希不变自动跳过）；失败自动重试 2 次（指数退避）；先写 `.part` 再改名；单条失败不影响整批，错误中文可复制；完成后汇总条数/时长/体积/异常清单。
- **交付**：zip 交付包（音频 + 清单.csv + 参数.json + README.txt 含 AI 合成声明）。

## 六、常见问题（含本课程实测 7 个坑）

> 这 7 个坑是上一轮用脚本拼 41 段配音踩过的，本软件已在后处理流水线里固化解决。

| # | 坑 | 现象 | 本软件的对策 |
|---|---|---|---|
| 1 | **采样率不统一** | 22.05kHz 按 44.1kHz 拼接 → 快放变调（"变形"） | 一律 `scipy.signal.resample_poly` 多相滤波重采样（`app/core/post.py` 禁邻近取样） |
| 2 | **MP3 编解码延迟** | 每段多出约 0.05+0.05 秒，41 段累计约 2.5 秒漂移 | 解码后剪掉头 `0.0502s`/尾 `0.0501s`（常量已注明来源，`post.MP3_DEC_DELAY_*`） |
| 3 | **soundfile 流式写 MP3** | 整轨削顶（−0.00dBFS） | MP3 一律 PCM WAV 母版 + `lameenc` 编码；soundfile 只用于 WAV/FLAC 写出和音频**解码** |
| 4 | **内存爆掉** | 全部音频读进内存 → OOM 被杀 | 逐条合成、逐条落盘、逐条释放；临时块即时删除（目标常驻 <400MB） |
| 5 | **edge-tts 网络** | 某些网络 403/超时 | 重试 2 次（指数退避）→ 自动降级 SAPI 离线音色并中文提示；设置里可配代理 |
| 6 | **命名与清单脱节** | 剪辑对不上段号 | 文件名严格按命名模板生成，同步增量写 `清单.csv`（UTF-8 BOM，Excel 直接打开） |
| 7 | **响度过冲** | MP3 编码后过冲削顶 | 真峰值（4× 过采样估计）归一到 −3dBFS，给编码过冲留余量；验收：解码后峰值 ≤ −2.5dBFS、满刻度样点 = 0 |

**其他常见问题**

- **试听失败：Edge-TTS 返回 403（网络环境被拒）**：这是网络环境被微软拒绝（校园网/机房常见）。
  点工具栏「⚙ 设置」→「网络代理」填入代理地址（如 `http://127.0.0.1:7890`，Clash/V2Ray
  的 http 入站端口），点「测试连接」确认通过后「保存并立即生效」——无需重启，音色会自动重新拉取。
  试听失败弹窗里也有「打开代理设置…」直达按钮。
- **试听 3 秒不出声**：Edge-TTS 需联网，检查网络；或按上一条配置代理。
- **生成的文件时长不对/变调**：确认「采样率」选了 44100（默认）；本软件任何路径都不会用"直接改采样率"。
- **断网后生成会不会丢文件**：不会。断网自动降级 SAPI；生成中强退也不留半截文件（`.part` 改名机制），重启后项目自动恢复。
- **Excel 打开清单乱码**：清单为 UTF-8 BOM；若仍乱码，用 Excel 的"数据→从文本/CSV"选 UTF-8。

## 八、设计决策（需求文档未写明处的取舍）

1. **停顿标记的实现**：文本按 `[pause=x]` 切成块分别合成，块间插入精确 `x` 秒静音；
   扣除清洗时保留的边缘静音（≤100ms），保证**语音间隙恰为 x 秒**（验收 ±0.1s）。
2. **流水线分两段执行**：文档 §3.2 的 ①重采样 ②剪延迟 ③去静音 对**每个引擎片段**执行
   （多段拼接时间轴对齐）；④淡入淡出 ⑤响度 ⑥编码 对**整条成品**执行（响度只归一一次，段间不跳变）。
3. **长文本自动按句切分**：超过引擎单次上限（Edge 约 2000 字）按句号/问号/分号切分，
   拼接边界做 20ms 交叉淡化（文档 §11 风险对策）。
4. **命名模板扩展名**：模板可写 `{i:02d}.mp3`；当输出格式改为 wav/flac 时**自动纠正扩展名**，
   避免"wav 内容 .mp3 后缀"造成剪辑软件困惑。CSV `文件名` 列优先于模板（仍会清洗非法字符）。
5. **词典与规则顺序**：词典显式替换 → 标准号（GB/T 24067 → GB/T 二四〇六七）→ 小数（2.0 → 二点零）
   → 整数＋单位（5000吨 → 五千吨）→ 全大写缩写（LCA → L C A；白名单如 NASA 按单词读）。
   每条规则可单独关闭；词典条目即"逐条覆盖"手段。逐位数字用"〇"（二四〇六七），小数点后用"零"（二点零）。
6. **断点哈希覆盖范围**：文本 + 音色 + 全部参数 + 发音词典；词典修改也会触发重做（否则读音对不上）。
7. **立体声输出**：内部按单声道处理（配音场景），输出选"立体声"时复制声道；不做伪立体声。
8. **响度默认真峰值 −3dBFS**：4× 过采样估计真峰值后归一，给 MP3 编码过冲留余量（坑 7）；
   LUFS 模式为 BS.1770-4 近似实现（48kHz K 计权 + 门限），硬限 −1dBFS。
9. **并发**：默认串行（并发 1，设置可调 2）。串行更稳、更易保证内存与网络配额。
10. **断点续传判定**：哈希一致且输出文件存在且上次成功 → 跳过；「只重做这一段」强制忽略哈希。
11. **示例数据**：`示例数据/蚕茧课程41段.csv` 为按课程主题撰写的演示文案（41 段），
    列结构与验收一致（序号,文件名,文本）；请用真实课程文案替换后做正式验收。
12. **UI 试听播放**依赖 QtMultimedia（Windows exe 自带）；缺组件时播放按钮置灰，仍可双击段落用系统播放器打开。
13. **代理配置即时生效**：「设置 → 网络代理」保存后立即重建引擎并重拉音色，无需重启；设置里带「测试连接」
    （实际拉一次音色清单验证），试听/生成的网络类失败弹窗均可直达代理设置。仅支持 http/https 代理。

## 九、合规声明（硬性要求）
