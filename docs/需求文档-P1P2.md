# 配音软件（TTS Studio）需求文档

> **一句话**：一个装在 Windows 电脑上的小软件 —— 左边挑"配音的人"，中间贴台词，右边调参数，点一下生成，批量导出 MP3。
> **分两期做**：**P1 网络数字配音（先做）** → **P2 音色克隆（后做）**。
> 版本：v1.0 ｜ 日期：2026-10-17 ｜ 编写：为本课程（《一枚蚕茧的低碳之旅》）配音流程产品化

---

## 0. 为什么做这个软件

本课程 18 分钟、41 段台词，是完全靠脚本拼出来的；过程中踩了 7 个坑（采样率、MP3 延迟、削顶、内存、命名、断点、响度）。**这些坑不该每次重踩**。

目标不是做一个通用产品，而是做一个**"教学视频配音工作台"**：

1. 一个列表选人（内置音色 + 自己克隆的音色，放在同一个列表里）；
2. 多段台词批量生成，**文件命名、分段、时长、响度全部自动规范化**，直接能丢进剪辑软件；
3. 参数可存成"预设"，下次一键复用；
4. P2 加上"我的音色"，让教师用本人的音色念标准普通话。

## 1. 用户与场景

| 角色 | 场景 | 痛点 |
|---|---|---|
| **教师（主用户）** | 做微课/精品课，需要十几分钟旁白、多个学生角色 | 自己录音时间长、普通话不标准；在线工具一次只能生成一句、命名混乱 |
| 教研组同事 | 帮忙改词、重录某几段 | 换软件就找不到参数、对不上时间轴 |
| 学校电视台 | 接收配音包，按段对轨 | 文件命名、时长、采样率不统一 |

**三个用户故事**

- **US-1**：我要把 41 段台词一次性生成 MP3，文件名是 `01.mp3 … 41.mp3`，采样率、音量都一致，直接拖进剪映。
- **US-2**：我改了一句台词，只想重做第 14 段，其余不动。
- **US-3**：我想用"我自己的声音"念剩下的段落，且听不出和前面不是同一次录的。

## 2. 分期路线

| 期 | 内容 | 引擎 | 关键交付 | 预估工作量 |
|---|---|---|---|---|
| **P1（本期）** | **网络数字配音**：音色列表、文本分段、参数面板、批量生成、试听、导出 | Edge-TTS（免费/免 Key）＋ Windows SAPI（离线兜底）＋（可选）Azure/讯飞/腾讯云 | 可运行 Windows 程序（exe）＋源码＋说明 | 单人 5–7 天（AI 辅助） |
| **P2（下期）** | **音色克隆**：录音质检→切分→训练/声纹→入库→同列表可选 | GPT-SoVITS（MIT，6GB 显存可推理）/ IndexTTS2（Apache-2.0，约 8GB）/ CosyVoice2（Apache-2.0，约 4GB）/ OpenVoice V2（音色迁移，CPU 可跑） | P1 的同一界面里多出"我的音色"分组 | 7–12 天 |

> **设计原则：P1 就把"引擎适配层 + 音色注册表"做对**，P2 只是插一个新适配器，界面和项目文件不用改。

### 3.1 引擎统一接口（**这是全项目最重要的 40 行**）

```python
from dataclasses import dataclass, field
from typing import Literal

@dataclass
class Voice:
    id: str                  # 全局唯一，如 "edge:zh-CN-YunxiNeural" / "clone:teacher01"
    name: str                # 显示名："云希（少年男声）"
    engine: str              # edge / sapi / azure / gpt_sovits ...
    lang: str = "zh-CN"
    gender: str = ""         # male / female / neutral
    tags: list[str] = field(default_factory=list)   # 旁白/少年/新闻/方言
    sample_path: str = ""    # 试听样音（首次生成后缓存）
    custom: bool = False     # 是否用户克隆音色

@dataclass
class TTSRequest:
    text: str
    voice_id: str
    rate: float = 0.0        # 0 = 原速；+0.2 = 快 20%
    pitch: float = 0.0       # 半音，±12
    volume: float = 0.0      # dB，±12
    style: str = ""          # 情感/风格（仅支持的引擎）
    style_degree: float = 1.0
    pauses: list[tuple[int, float]] = field(default_factory=list)  # (字符位置, 秒)
    out_format: Literal["mp3", "wav", "flac"] = "mp3"
    sample_rate: int = 44100
    bitrate: int = 128
    normalize: Literal["peak", "lufs", "none"] = "peak"
    target_db: float = -3.0
    lexicon: dict[str, str] = field(default_factory=dict)  # 发音词典覆盖

@dataclass
class SynthResult:
    path: str
    duration: float
    sample_rate: int
    warnings: list[str] = field(default_factory=list)

class Engine(Protocol):
    name: str
    def list_voices(self) -> list[Voice]: ...
    def capabilities(self) -> dict: ...          # 支持哪些参数
    def synth(self, req: TTSRequest, out_path: str, on_progress=None) -> SynthResult: ...
    def preview(self, voice_id: str, out_path: str) -> SynthResult: ...   # 固定测试句
```

### 3.2 一条音频的**标准后处理流水线**（必须固化，别每次重写）

```
引擎原始输出
  → ① 统一重采样（多相滤波 resample_poly，禁止邻近取样）
  → ② 若源是 MP3：剪掉编解码延迟（实测 头 0.0502s / 尾 0.0501s）
  → ③ 去首尾静音（阈值 -45dBFS，保留 100ms 呼吸）
  → ④ 淡入淡出 10ms
  → ⑤ 响度：峰值 -3.0dBFS（默认）/ 或 LUFS -16
  → ⑥ 编码：MP3 用 lameenc（**绝不用 soundfile 流式写 MP3**）
```

### 4.3 参数面板（FR-P）

| 编号 | 参数 | 范围 | 默认 | 说明 |
|---|---|---|---|---|

| FR-P-4 | 情感/风格 style | 依引擎 | 空 | 仅 Azure 等支持的引擎显示（不支持时置灰并说明） |
| FR-P-5 | 风格强度 style_degree | 0.1 ~ 2.0 | 1.0 | 同上 |
| FR-P-6 | 采样率 | 22050 / 24000 / 44100 / 48000 | 44100 | 项目级统一 |
| FR-P-7 | 码率 | 64/96/128/160/192 kbps | 128 | 只对 MP3 |
| FR-P-8 | 声道 | 单声道 / 立体声 | 单声道（配音） | 课程旁白用单声道足够 |
| FR-P-9 | 响度归一 | 峰值 / LUFS / 关 | 峰值 −3dBFS | 防 MP3 过冲削顶 |
| FR-P-10 | 输出格式 | mp3 / wav / flac | mp3 | |

## 5. P2 功能需求（音色克隆）

| 编号 | 需求 | 级别 |
|---|---|---|
| FR-C-1 | **录音质检**：导入干声，自动报告时长、信噪比、削顶、静音段比例，给出"能否用于克隆"的结论与建议 | M |
| FR-C-2 | 自动切分（按静音）＋人工微调（波形上拖动边界） | M |
| FR-C-3 | ASR 自动标注文本，可编辑（训练需要文本-音频对） | M |
| FR-C-4 | 一键"训练/提取声纹"：调用所选后端（GPT-SoVITS / IndexTTS2 / CosyVoice2 / OpenVoice），显示进度与日志 | M |
| FR-C-5 | 训练产物入库为 Voice（`custom=True`），**与内置音色同列表**，可试听、可删除、可备份 | M |
| FR-C-6 | 克隆音色的参数面板与 P1 完全一致（差异项置灰并说明） | M |
| FR-C-7 | **音色迁移模式**（OpenVoice）：把已有 AI 音频换成某音色，**保持时长不变**（用于"已经配好音、只想换音色"） | S |
| FR-C-8 | 合规：训练前弹出"仅可克隆本人或已获授权的声音"确认；生成文件写入 AI 生成标记（元数据/旁注） | M |

**P2 后端选型（供实现时定）**

| 后端 | 许可 | 硬件 | 输出 | 适合 |
|---|---|---|---|---|
| **GPT-SoVITS v2Pro / v4** | MIT | 推理 ≥6GB 显存；微调建议 12GB | v4 原生 48kHz | 中文克隆最稳、社区资料多，"1 分钟素材微调" |
| IndexTTS2 | Apache-2.0 | 约 8GB | 24kHz | 情感控制、**时长可控**（配画面强） |
| CosyVoice2-0.5B | Apache-2.0 | 约 4GB | 24kHz | 3 秒零样本、轻量 |
| OpenVoice V2 | MIT（本课已用） | CPU 可跑 | 22.05kHz | **音色迁移**，快，但略闷 |

> 本课程已验证：OpenVoice V2 + 7 分钟干声 → 41 条配音，时长漂移 <0.02 秒。P2 可先接它跑通链路，再接 GPT-SoVITS 提升相似度与音质。

## 7. 非功能需求

| 类别 | 要求 |
|---|---|
| 平台 | Windows 10/11 x64（主）；代码保持跨平台，macOS/Linux 可运行 |
| 安装 | 提供 exe 安装包或免安装 zip；**首次运行不需要命令行** |
| 依赖 | P1 仅需 Python 3.11 + PySide6 + edge-tts + numpy + soundfile + lameenc + scipy |
| 性能 | 41 段/约 16 分钟文本，单音色批量生成 ≤ 10 分钟（网络正常） |
| 内存 | 常驻 < 400MB；批量时逐条释放（不把全部音频读进内存） |
| 稳定性 | 任意单条失败不影响其余；进程崩溃后能恢复项目 |
| 网络 | Edge-TTS 需联网；失败时自动降级 SAPI 并提示 |
| 隐私 | 文本与音频不上传第三方（除所选云引擎本身）；日志不记录全文，只记前 20 字 |
| 合规 | 仅支持克隆本人/已授权声音；导出附加"AI 合成语音"说明文件 |
| 可维护 | 新引擎 = 新增一个 `engines/xxx.py`，不改核心 |

## 9. 验收标准（P1 通过条件）

**A. 功能验收**

1. 打开软件 → 能从列表选到"云希"，点试听 → 3 秒内出声。
2. 粘贴 41 段（用随包 `示例数据/蚕茧课程41段.csv`）→ 点"全部生成" → 10 分钟内完成，输出 `01.mp3 … 41.mp3`。
3. 生成的 MP3：44.1kHz、单声道、峰值 ≤ −2.5dBFS、**无削顶**（满刻度样点 = 0）。
4. 改第 14 段文字 → 再点"全部生成" → **只重做第 14 段**，其余跳过（断点续传生效）。
5. 把音色换成"晓晓"、语速 −5% → 参数被记住，重新打开项目仍生效。
6. 导出交付包 zip（音频＋清单.csv＋参数.json）。

**B. 质量验收**

7. 同一条文本连续生成 3 次，时长差异 < 5%，无爆音。
8. 文本含 `[pause=1.5]` 时，该处确实停顿 1.5 秒（±0.1 秒）。
9. 文本含 `2.0千克`、`GB/T 24067`、`LCA` 时，读法符合词典/规则设置。

**C. 稳定性**

10. 断网后再生成 → 不崩溃，自动降级 SAPI 并给出清晰提示。
11. 生成中强制退出 → 重启后项目还在，已生成文件可识别。

## 10. 已知坑（本课程项目实测，实现时必须绕开）

| # | 坑 | 现象 | 对策 |
|---|---|---|---|
| 1 | **采样率不统一** | 22.05kHz 音频按 44.1kHz 拼接 → **快放变调（"变形"）** | 一律用 `resample_poly` 重采样到项目采样率 |
| 2 | **MP3 编解码延迟** | 每段多出约 0.05+0.05 秒 → 41 段累计 2.5 秒漂移 | 解码后剪掉头 0.0502s / 尾 0.0501s（可自动探测） |
| 3 | **soundfile 流式写 MP3** | 整轨削顶（−0.00dBFS） | 只用 PCM WAV 母版 + `lameenc` 编码 |
| 4 | **内存** | 模型与音频同驻 → OOM 被杀 | 逐条独立进程/逐条释放；长音频分块处理 |
| 5 | **edge-tts 网络** | 某些网络环境 403/超时 | 代理设置、重试、降级 SAPI；**不要在内网服务器上跑** |
| 6 | **命名与清单脱节** | 剪辑对不上段号 | 生成时强制按模板命名并写清单 |
| 7 | **响度过冲** | MP3 编码后过冲削顶 | 归一目标留 −3dBFS 余量 |

## 11. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| Edge-TTS 非官方接口，可能变更/限流 | P1 不可用 | 抽象成适配器；内置 SAPI 兜底；预留 Azure 官方 Key 通道 |
| 用户机器无 GPU | P2 跑不动 | P2 默认接 OpenVoice（CPU 可跑）；GPT-SoVITS 检测显存后给结论 |
| 克隆音色被滥用 | 合规风险 | 强制"本人/授权"确认；导出附 AI 合成标记；不提供去水印等功能 |
| 长文本超引擎上限 | 生成失败 | 自动按句切分后拼接，边界加 20ms 淡入淡出 |
